# مهمة تطوير موجّهة إلى Claude Code

**الهدف:** بناء تطبيق جديد من الصفر استنادًا إلى التقرير المرفق.
**المرجع:** `reports/<run>/BLUEPRINT.md` + صور الصفحات.
**الحدود:** إعادة تنفيذ مستقلة، لا أخذ كود خاص أو محتوى محمي أو قواعد بيانات.

## خطوات ملزمة

1. استخرج جدولًا بالأدلة: الصفحة، العنصر، السلوك المرصود، درجة الثقة.
2. قدّم خريطة الصفحات ونظام التصميم والمكونات المشتركة.
3. اكتب المتطلبات غير المرئية كأسئلة محددة، ولا تدّع أنها مستخرجة.
4. أنشئ واجهة متجاوبة ومكونات قابلة للاختبار.
5. أنشئ Backend/API/Database جديدة فقط بناء على مواصفات مؤكدة أو يوافق المستخدم على افتراضاتها.
6. اكتب اختبارات E2E ولقطات مقارنة تحت ظروف شاشة موحّدة.
7. سجّل النواقص والمخاطر والخصائص غير المكتملة في `PARITY.md`.
