# سياسة الاستخدام المصرح

يمكن تحليل مواقع تملكها أو لديك إذن مكتوب بتحليلها، وكذلك دراسة واجهات متاحة للعامة ضمن حدود القوانين وشروط الاستخدام والسياسات المعلنة. الاستنساخ التطبيقي ينبغي أن ينتج تنفيذًا مستقلاً، لا إعادة نشر نصوص أو شعارات أو صور أو علامات تجارية محمية بلا إذن.

**الممنوع في سير العمل:** تخطي المصادقة أو تدابير الحماية؛ الوصول إلى حسابات أو قواعد بيانات الغير؛ جمع معلومات شخصية؛ اختبار أمني هجومي دون تصريح؛ تقليد واجهات دخول أو دفع بقصد انتحال جهة؛ نسخ الأسرار والمفاتيح.

الهدف من مقارنة المواقع هو التعلم، التدقيق المصرح، والتطوير المستقل. عندما تكون المعلومات غير ظاهرة، سجّلها بوصفها مجهولة ولا تدّع استخراجها.
