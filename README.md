# CloneCraft Studio

مختبر محلي لتحليل بنية المواقع المصرح بفحصها وإنشاء مخططات إعادة بناء مستقلة.

**النسخة التأسيسية 0.1** — واجهة عربية، ماسح Playwright للصفحات العامة، لقطات الشاشة، تقارير JSON وBLUEPRINT، وتعليمات Claude Code. لا يتضمن حتى الآن توليدًا آليًا لتطبيق مكتمل.

راجع ملف README الكامل وتعليمات التشغيل المرفقة ضمن المشروع بعد اكتمال رفع الملفات.
